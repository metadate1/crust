# Source-publication decision

## 2026-09-02

**Decision owner:** Dominykas Norvilas (`metadate1`)

The project owner directed CRUST to be prepared for public source visibility under its current
all-rights-reserved, source-available boundary.

The approved publication model is:

- source and documentation only;
- no game disc, ROM, BIOS, executable, extracted stream, save, replay, screenshot, recording, or
  other game-derived file;
- no compiled native release, Wasm bundle, package, or other generated build output committed to
  this source repository;
- users supply their own supported game data locally; and
- no claim that CRUST is open source, clean-room, affiliated with, or endorsed by any game or
  console rights holder.

A separately operated browser site may build this source and ask each user to select their own
supported game file locally. Such a site must not bundle, upload, retain, or distribute game data,
firmware, captures, or other third-party assets. Site deployment is separate from publishing this
source repository and must keep its own privacy, security, and distribution review current.

The owner acknowledges the unresolved upstream and game-rights questions described in
[RIGHTS_AND_LICENSES.md](../RIGHTS_AND_LICENSES.md). The repository safeguards and history audit
reduce the risk of publishing game data or secrets. They do not settle those rights questions or
provide a legal opinion.

Changing repository visibility remains a separate action. This record does not authorize a
visibility change by itself.
