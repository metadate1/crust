# Documentation guide

Use this page to find the right document without reading the full verification history.

## Start here

- [Project README](../README.md) explains what CRUST is, what works, and how to run it.
- [Compatibility](COMPATIBILITY.md) lists supported behavior and known gaps.
- [Development](DEVELOPMENT.md) contains build, test, and local-data commands.
- [Architecture](ARCHITECTURE.md) explains the main components and safety boundaries.

## Evidence and history

- [Verification record](VERIFICATION.md) is a dated technical log. Newer entries can supersede
  older results.
- [Browser campaign replay](BROWSER_CAMPAIGN_REPLAY.md) defines how local replay fragments are
  discovered, joined, and tested without inventing input or forcing game state.
- [Migration evidence](MIGRATION.md) records contracts preserved or deliberately corrected during
  the Rust migration.

These files contain exact frame counts, state values, hashes, and commands. They are evidence, not
quick-start guides.
